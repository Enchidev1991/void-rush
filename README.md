# VOID//RUSH — Prototype 01

First vertical slice:
- one anti-gravity craft
- one closed 3D test circuit
- chase camera
- touch drag steering
- thrust and brake controls
- basic hover/banking presentation
- mobile-first rendering

## Run locally
Because this uses ES modules, serve the directory with any static web server rather than opening `index.html` as a local file.

Example:
`python3 -m http.server 8080`

Then open `http://localhost:8080`.
